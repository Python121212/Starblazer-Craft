# シームレスな高高度・宇宙環境の試作（0.2.0）

## 重要：飛行高度と建築高度は別

この試作では、**オーバーワールド内の Y=5000 をプレイヤーの飛行上限・宇宙環境の境界**にします。
別ディメンションへの転送は行わないので、境界を越えるための読み込み画面は入りません。
通常のチャンク読み込み・通信・描画の待ち時間までなくなる保証ではありません。

**ブロックを設置できる上限は変更しません（通常のオーバーワールドでは Y=319 まで）。**
Y=5000まで地形・建築範囲を拡張するMODではありません。Minecraft 1.20.1 の標準設定の高さ制限もあります。
乗っているエンティティ全体の上限処理は未実装です。現在の上限補正は非騎乗プレイヤーが対象です。
宇宙空間での建築・歩ける船体・自由建造の船・惑星はまだ実装していません。

## 高度区分と共通計算

高度はブロック座標単位、速度はブロック/tickです。20tick=1秒を基準にします。
実際の大気層の縮尺・万有引力ではなくゲーム用の近似です。

| 高度 | 区分 | 空気密度倍率（区間の始点→終点） |
|---|---|---|
| Y=320～800 | 対流圏～成層圏への移行 | 1 → 0.85 |
| Y=800～2000 | 成層圏 | 0.85 → 0.12 |
| Y=2000～3500 | 中間圏～熱圏 | 0.12 → 0.005 |
| Y=3500～5000 | ほぼ真空 | 0.005 → 0 |
| Y=5000 | 宇宙環境 | 0 |

各倍率は smoothstep でつなぎ、境界で不連続に切り替えません。
重力はY=3500までは通常、そこから徐々に弱めてY=5000で0になります。
真空と無重力は本来別ですが、ここではゲーム上のルールとして高度に対応付けます。
`AtmosphereProfile` はMinecraftに依存しないJavaの計算クラスです。

## 今回有効になる処理

### 同じワールド内の飛行上限

非騎乗プレイヤーがY=5000を超えた場合、サーバーが同じワールドのY=5000へ位置を補正します。
上向きの速度は止めます。クリエイティブ・スペクテイターも上限補正の対象です。
ただしゲーム内コマンドなどで意図的に繰り返し上限を超える操作をした場合、補正が見える可能性があります。

### エリトラ

- Y=1200～1500で水平方向の減衰と下向き加速を徐々に増やします。
- Y=1500以上では滑空状態を解除します。ロケットを使っても通常の低高度のような滑空はできません。
- クリエイティブ・スペクテイターはこの制限の対象外です。
- 航空機の揚力方程式の完全実装ではなく、バニラのエリトラ移動に対する試作補正です。

### 酸欠

- サバイバル・アドベンチャーでY>1500から酸欠曝露値が増加します。
- Y=1500付近ではゆっくり、Y>=2000では1tickにつき1増加し、200で上限になります。
- 200に達すると40tickごとの判定で1ダメージを与えます。Y>=2000では開始から約10～12秒が最初の被ダメージの目安です。
- Y<=1500へ降下すると曝露値を解除します。通常の水中呼吸ゲージは変更しません。
- 再ログイン・ディメンション変更で曝露値を解除します。永続的な酸素管理・装備・与圧室は未実装です。
- バニラのボートやトロッコに乗っても酸欠を回避できません。
- クリエイティブ・スペクテイターは酸欠ダメージを受けません。

### 重力

Forge の重力属性に専用の一時倍率を適用します。元の属性値や他MODの修飾子は上書きしません。
`NoGravity` フラグも書き換えません。降下・別ディメンション・モード変更時は本MODの倍率を解除します。
同期更新を抑えるため、適用する重力倍率は1%刻みです（共通計算自体は連続値）。
無重力でもバニラの移動減衰は残るため、完全な慣性航行ではありません。
推進器がない段階でも降りられるよう、Y=5000付近ではShiftで下向きに加速できます。

### 空と霧

Y=320より上で空に濃紺の重ね描画を徐々に加えます。Y=2000～3500で固定の星が現れ、上空では昼でも見えます。
空の描画段階で処理し、地形やGUIの上から全面を塗りつぶしません。水・溶岩・粉雪内では追加の空／霧補正を行いません。
専用の空テクスチャ・新しいGUIは追加していません。独自シェーダーや他の空描画MODとの互換性は未検証です。

## 計算のみ・未接続の機能

- 空気抵抗：`density` を返しますが、全エンティティへ空気抵抗を適用する実装ではありません。
- 風切り演出強度：`density * speed² / 4` を0～1に制限。
- 再突入演出強度：降下中・Y>=800で `density * speed³ / 32` を0～1に制限。
- 星空の強さ・酸素倍率・エリトラ揚力倍率も共通計算から取得できます。

**薄雲、風切り音、エンジン音のこもり、振動、再突入の発光・加熱・損傷、機体姿勢制御、宇宙船の慣性航行は未実装です。**
船が未実装のため、船の速度を演出へ渡す処理もまだありません。高度だけで一律に燃える処理は追加していません。

## 検査と負荷

境界値、単調性、連続性、無効な入力、速度による演出強度、滑空・酸素の倍率をJUnitで検査します。
ブロック走査・地形生成・強制チャンクロードを行わず、プレイヤーごとに定数時間で計算します。
星は固定512個で、フレームごとの乱数生成やチャンク処理は行いません。
実機のFPS・サーバーMSPT・通信量の測定は未実施です。負荷ゼロやラグなしを保証しません。

## 実機確認手順（未実施）

新しいテストワールドで行ってください。落下・酸欠で死亡するため、重要な所持品を持ち込まないでください。

1. クリエイティブで `/tp @s ~ 1200 ~`、`2000`、`3500`、`5000` を試し、座標と空・星を確認。
2. Y=5100へ移動し、Y=5000へ補正されること、ディメンション切り替え画面がないことを確認。
3. エリトラを装備して1200～1500の挙動と、1500以上の滑空解除を確認。
4. サバイバルでY=2000に移動し、猶予後のダメージと、Y=1400へ戻ったときの解除を確認。
5. サバイバルのY=5000で無重力とShift下降を確認。酸欠ダメージに注意。
6. 別ディメンション・再ログイン・死亡・モード切り替え後に重力が残らないことを確認。
7. マルチで位置補正・重力属性同期・エリトラの動作と、専用サーバーの起動を確認。
