# レンチ：範囲選択の試作（0.1.0）

## 現在できること

レンチアイテムを Forge に登録しました。Create などの他 MOD は不要です。
クリエイティブの「道具と実用品」タブ、または以下のコマンドで入手できます。

```mcfunction
/give @s starblazercraft:wrench
```

![レンチの16×16テクスチャ](../src/main/resources/assets/starblazercraft/textures/item/wrench.png)

**今回は範囲選択の保存までです。エンティティ化・移動・描画・物理演算は未実装です。**
選択完了時にもワールドのブロックは削除・変更しません。
0.3.1から通常のワールドに [コアブロック](CORE.md) を設置して開始できます。テスト用タグは不要です。

## 操作（メインハンドにレンチを持つ）

|操作|結果|
|---|---|
|コアを右クリック|新しい選択を開始。前の端点・追加ブロックを解除|
|端のブロックを右クリック|1点目を保存|
|対角のブロックを右クリック|2点目を保存し、直方体の範囲を確定|
|選択中に Shift＋左クリック|クリックしたブロックを追加選択。ブロックを壊さない|
|Shift＋空中右クリック|選択をすべて解除|
|2点確定後、コア以外を右クリック|1点目を取り直す。追加ブロックは維持|

「右端→左端」などの順序制約はありません。上下を含む3次元の対角2点を指定できます。
コアの右クリックは**開始モードへの切り替え**で、ボタンを押し続ける必要はありません。
コア自身を端点にする場合は、別の端点を使ってコアを含む直方体を選ぶか、コアを追加選択してください。
追加選択は端点選択の前後どちらでも可能です。
追加ブロックは直方体を拡張するのではなく、**個別の座標の集合**として保持します。
範囲内のブロックを追加しても、将来の組み立て時には和集合として扱う予定です。

## 制限と保存

- 直方体：端点を含め最大 **4096マス**（空気のマスも体積に含む）。超過時は2点目を保存せず再選択。
- 追加座標：最大 **256個**。同じ座標は重複保存しない。
- 追加座標とコアを結ぶ直方体も4096マス以内に制限。遠方への追加を防止。
- コアは直方体または追加座標に含める。
- 選択情報はレンチの NBT `StarblazerSelection` に保存：所有者 UUID、ディメンション ID、コア、端点2点、追加座標。
- 保存したレンチを渡しても、他プレイヤーはその選択を編集できない。新しいコアで開始するか解除する。
- 別ディメンションでは選択を続けられない。
- コアが消失、または未読み込みの場合は続行しない。チャンクを強制ロードしない。
- スペクテイターと建築不可のプレイヤーには操作を許可しない。
- サーバー側で選択を更新。体積判定は計算のみで、範囲の全ブロック走査はしない。

チェストなどを右クリックした場合も、GUI を開くよりレンチの選択操作を優先します。

この段階では選択枠・追加座標のハイライトはありません。メッセージとレンチのツールチップで確認します。
土地保護 MOD との連携は未実装です。将来の実変換時には、各ブロックの権限・ロード状態・ブロックエンティティの保存可否を再検証します。

## 別のブロックをコアとして使うテスト（任意）

正式なコアとして `starblazercraft:core` を登録済みです。追加で別ブロックを試したい場合のみ、以下を使います。
テストワールドでのみ、データパックのタグに任意のブロックを設定できます。
例えば以下を `data/starblazercraft/tags/blocks/assembly_cores.json` に置きます。

```json
{
  "replace": false,
  "values": ["minecraft:gold_block"]
}
```

データパックのルートには `pack.mcmeta` が必要です（Minecraft 1.20.1 はデータパック形式15）。

```json
{"pack":{"pack_format":15,"description":"Temporary wrench selection test"}}
```

`/reload` 後、金ブロックを設置してレンチで右クリックします。
通常の石などで対角2点を選び、金ブロックを範囲に含めてください。
範囲外の近くの石を Shift＋左クリックして追加し、破壊されないことを確認します。
巨大な範囲の拒否、追加の重複、解除、再ログイン後の保存も確認項目です。

## 0.1.1：3D モデル

レンチに5個の直方体からなる厚み付きモデルを追加しました。
一人称・三人称の左右それぞれの持ち方と、GUI・地面・額縁の表示を設定しています。
インベントリも同じ立体モデルの表示です。以前の平面アイコン固定ではありません。

[テクスチャ一覧](../テクスチャ一覧.md) で元テクスチャと手持ち姿勢の PNG を確認できます。
PNG はモデルから生成した見本であり、ゲーム内の実機撮影ではありません。

## 0.1.2：参考画像に合わせた銀色レンチ

`画像/IMG_0185.png` を参考に、黒い輪郭と銀色の濃淡、斜めの持ち手、開いた先端のデザインに変更しました。
参考画像は256×256のまま保存し、本番用の画像は背景を透明化して16×16に変換しています。
立体モデルは不透明ピクセルの輪郭に沿った14個の行セグメントで構成し、厚みは2モデル単位です。

明示的にデザインを再生成するときだけ、以下を実行します。

```sh
python3 scripts/generate_wrench_model.py
python3 scripts/generate_texture_index.py
```

参考フォルダーに画像を入れただけでは、デザイン変更・自動テスト・サイト公開は行いません。

## 0.1.3：選択時の設置音

- コアの選択開始、1点目、2点目、Shift＋左クリックによる追加の**成功時だけ**、クリックしたブロックの位置で設置音を再生します。
- 対象ブロックの `BlockState#getSoundType(level, pos, player)` から設置音を取得します。木・石・金属などで音が変わり、文脈依存の SoundType にも対応します。
- 音量・ピッチは通常のブロック設置時と同じ式を使います。サウンド設定の「ブロック」で調整できます。
- サーバーから、操作した本人を含む周囲のプレイヤーへ通知します。クライアントで重ねて鳴らしません。
- 無効な選択・範囲超過・追加済み座標・空中での解除では選択音を再生しません。
- ワールドのブロックを実際に設置・破壊する処理は追加していません。`サウンド/` の参考音源も取り込みません。
